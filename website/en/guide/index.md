# OpenYoink Guide

OpenYoink is a temporary landing spot for files, folders, images, text, and links while you switch windows, Spaces, or full-screen apps.

## Start here

1. [Complete your first drag](./quick-start).
2. [Understand file safety](./file-safety).
3. [Learn about OpenYoink Island](./island).

If you are comparing macOS drag-and-drop utilities, read [Why OpenYoink](./open-source-drag-shelf) for common workflows, local-first behavior, and how a drag shelf differs from the clipboard.

::: tip Available in v1.6.5
The current stable build prevents browser tabs and other non-file drags from revealing the shelf at the screen edge. Real files, folders, and file promises still trigger it, and the Quick Access module introduced in v1.6.4 continues to follow the current macOS default file manager.
:::
